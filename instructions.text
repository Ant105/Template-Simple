----------❗️❗️Минификация JS---------------


npm install --save-dev terser

❓npx terser src/app.js -o dist/app.min.js --compress --mangle

--compress — удаляет лишние выражения, dead code
--mangle — сокращает имена переменных / функций

Просто минимизировать:
terser input.js -o output.min.js
Минимизировать и сжать сильнее:
terser input.js -o output.min.js -c -m


❓❓
Безопасный вариант compress
terser input.js -o output.min.js \
  -c arrows=false,collapse_vars=false,comparisons=false,computed_props=false,\
hoist_funs=false,hoist_props=false,hoist_vars=false,inline=0,join_vars=false,\
keep_fargs=true,loops=false,negate_iife=false,properties=false,pure_getters=false,\
reduce_funcs=false,reduce_vars=false,sequences=0,side_effects=false,typeofs=false \

----------Babel---------------
Команда (настройки в конфиге и в browserslist в package.json):
npx babel main.js -o main.babel.js

Замечания:
❗️Babel не всегда нужен, уточняй нужна ли поддержка старых браузеров или только
современных, во втором случае babel чаще всего не нужен
-
❗️Если используешь babel не забывай что его нужно применять до минификации JS
-
Если когда то будешь работать с js модулями и решишь использовать эту "недо-сборку"
знай что я не знаю будет ли оно работать с модулями
-
Я использовал .babelrc вместо babel.config.js так как он проще для небольших проектов
но тут нельзя использовать переменные и условия прямо в конфиге

Качал:
npm install --save-dev @babel/core @babel/cli @babel/preset-env
npm install --save core-js
