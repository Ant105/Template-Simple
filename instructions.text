----------Минификация HTML---------------------
Команда (настройки в самой команде):
npx html-minifier-next --collapse-whitespace --conservative-collapse --remove-comments -o index.html index.html

Замечания:
❗️❗️❗️Как можно заметить я не добавил тут суффикс для аутпута (аутпут тут указан первым)
это потому что суффикс в index.html может сломать сайт на многих хостингах и я боялся 
что я забуду его убирать вручную

Качал:
npm install --save-dev html-minifier-next

----------PostCSS(doiuse/preset-env/cssnano)------
Команда (настройки в конфиге и в browserslist в package.json):
npx postcss styles.css -o styles.min.css
❗️ВАЖНО: doiuse по умолчанию стоит до preset-env но если ты хочешь взглянуть что оно 
напишет после работы preset-env можешь просто раскоментировать и закоментировать нужный 
код, главное не забудь потом изменить это
❗️ВАЖНО 2: Чтобы понять какие предупреждения от doiuse имеют значение можешь 
использовать ИИ, Can I Use или нечто подобное

Замечания:
Хотя в большенстве своем уровень оптимизации у postcss-preset-env зависит от stage
также оно смотрит на browserslist в package.json

Качал:
npm install postcss postcss-cli --save-dev
npm install postcss-preset-env cssnano --save-dev
npm install doiuse --save-dev
----------------------------------------------------




---------Проверка кроссбраузерности/валидности JS/нужен ли Babel-----------
Команда:
npx eslint main.js

Замечания:
Конфиг сильно зависит от моего (в момент когда я это пишу) нынешнего стэка,
когда у тебя поменяются технологии, например когда ты начнешь использовать 
❗️модульный JS, TypeScript, JS фреймворк, NodeJS нужно будет сильно менять этот конфиг
-
❗️Используй ДО babel (хотя может это очевидно)
-
В данный момент я использую так называемый compat-flat конфиг но скорее всего скоро 
(или по крайней мере через 1-2 года) ESLint начнет требовать чистый flat конфиг,
так что если ты будешь обновлять этот плагин будь готов к возможности того что
нынешний синтаксис конфига перестанет быть валидным

Качал:
npm install --save-dev eslint
npm install --save-dev eslint-plugin-compat
npm install --save-dev eslint-config-prettier
---------------------------------------------------------------------------



----------Минификация JS---------------
Команда:
npx terser main.js --config-file .terserrc -o main.min-three.js

Замечания:
❗️Конфиг не подходит для модульного JS, как минимум из-за отсутствия "module": true
-
Я использовал .terserrc вместо terser.config.js потому что кажется тут меньше шанс
получить какую то проблему но тут нельзя будет использовать переменные/циклы и тому
подобное для сложного конфига и тут JSON синтаксис
-
Если будешь использовать terser после babel смотри нужно ли менять значения ecma

Качал:
npm install --save-dev terser
---------------------------------------



----------Babel---------------
Команда (настройки в конфиге и в browserslist в package.json):
npx babel main.js -o main.babel.js

Замечания:
❗️Babel не всегда нужен, уточняй нужна ли поддержка старых браузеров или только
современных, во втором случае babel чаще всего не нужен
-
❗️Если используешь babel не забывай что его нужно применять до минификации JS и что в 
конфиге для terser иногда нужно поменять значения ecma а также добавить суффикс babel 
для команды terser
-
Если когда то будешь работать с js модулями и решишь использовать эту "недо-сборку"
знай что я не знаю будет ли оно работать с модулями
-
Я использовал .babelrc вместо babel.config.js так как он проще для небольших проектов
но тут нельзя использовать переменные и условия прямо в конфиге

Качал:
npm install --save-dev @babel/core @babel/cli @babel/preset-env
npm install --save core-js
